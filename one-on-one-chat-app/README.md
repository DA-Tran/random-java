
# One-on-One Chat App (Vanilla JS WebSocket)

## Files
- index.html - UI
- style.css - Responsive modern design
- chat.js - WebSocket client, messages, echo server demo

## Run
```bash
start one-on-one-chat-app/index.html
```

**Demo**: Enter name, connect (uses public WebSocket echo), send messages. Open second tab for simulation. Echo reflects back.

**Note**: True P2P needs signaling; this is functional client demo.
